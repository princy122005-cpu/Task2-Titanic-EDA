# Task 2 – Titanic Exploratory Data Analysis (EDA)

## Project Overview
This project is part of Task 2 and focuses on Exploratory Data Analysis (EDA) of the Titanic dataset using Python.

## Dataset
Source:
https://raw.githubusercontent.com/datasciencedojo/datasets/master/titanic.csv

## Tools & Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Insights
- Female passengers had a higher survival rate.
- First-class passengers survived more than third-class passengers.
- Younger passengers had better survival chances.
- Fare shows a positive correlation with survival
